# Praxistests: Microsoft 365, Copilot und KI-Agenten

Stand: November 2026. Ergänzend zum [Buch](../README.md): Was bei Tests in einem eigenen Testtenant herauskam, was tatsächlich funktioniert, was es kostet, welche Infrastruktur nötig ist und wo die Grenzen liegen.

Alle Tests liefen mit erfundenen Daten. Firmen, Personen und Projekte in den Beispielen sind ausgedacht. Zahlen und Preise beziehen sich auf den Stand der Tests und können sich ändern.
